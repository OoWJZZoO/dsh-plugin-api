# docs/standards — 全局 feature 设计规范

本目录收录所有 feature 设计必须遵守的**全局规范**（跨 feature 的治理口径与设计约束），是 AGENTS.md 之外的规范落脚点。任何 feature（含 M4/M5/M6 及后续）进入 Stage 0–3 时，先检查并遵守本目录条文。

规则：

- 新增全局规范落盘本目录，并在 AGENTS.md §6 登记指针；AGENTS.md 不承载规范正文，只承载 constitution 与指针。
- 规范修订影响能力边界时，必须同步 AGENTS.md §2/§4 与 `docs/specs/plugin-api-features/feature-list.md`（同 AGENTS.md §6 既有规则）。
